# 🎲 루빅스 큐브 솔버

> 섞여진 루빅스 큐브를 색상으로 입력하면 최적의 해결 순서를 단계별로 안내해 드립니다.

---

## ✅ 구현된 기능

### 1. 큐브 색상 입력
- 6면(U/R/F/D/L/B) × 9칸 = 54칸 전개도 UI
- 색상 팔레트(흰/노랑/빨강/주황/파랑/초록) 클릭 선택
- 셀 클릭으로 색상 지정 / 같은 색 재클릭 시 제거
- 실시간 색상 개수 카운터 (9개 초과 시 경고)

### 2. 유효성 검증 (2단계)
- **실시간**: 색상별 9개 초과 여부 즉시 감지
- **최종 검증 (해결하기 버튼)**:
  - 미입력 칸 존재 여부
  - 색상별 개수 9개 여부
  - 센터 조각 6개 색상 유일성
  - 코너 조각 물리적 불가능 조합 감지
  - 엣지 조각 물리적 불가능 조합 감지

### 3. IDA* 해결 알고리즘
- 최대 20수 이내 해결 (God's Number)
- 검증된 facelet 치환 테이블 기반
- 반대 면 중복 이동 제거로 최적화

### 4. 단계별 해결 안내
- 전체 이동 기보 (칩 형태로 표시)
- 이전/다음/처음/끝 네비게이터
- 현재 이동 카드 (이동명 + 상세 설명)
- 기보 칩 클릭으로 원하는 스텝으로 이동

### 5. 3D 큐브 미리보기
- CSS 3D Transform 기반 3D 큐브
- 마우스/터치 드래그로 자유 회전
- 스텝 이동 시 3D 큐브 실시간 동기화
- 아이들 상태 자동 회전 애니메이션

## 📁 파일 구조

```
index.html          - 메인 UI (전개도, 3D뷰, 솔루션 패널)
css/
  style.css         - 전체 스타일 (다크 테마)
js/
  cube-solver.js    - 큐브 모델 + 유효성 검증 + IDA* 알고리즘
  cube3d.js         - 3D 큐브 드래그 제어
  main.js           - 메인 컨트롤러 (UI 이벤트, 솔루션 표시)
README.md
```

## 🔡 큐브 표기법

| 기호 | 의미 |
|------|------|
| U / U' / U2 | 윗면 시계 / 반시계 / 180° |
| D / D' / D2 | 아랫면 시계 / 반시계 / 180° |
| F / F' / F2 | 앞면 시계 / 반시계 / 180° |
| B / B' / B2 | 뒷면 시계 / 반시계 / 180° |
| L / L' / L2 | 왼쪽면 시계 / 반시계 / 180° |
| R / R' / R2 | 오른쪽면 시계 / 반시계 / 180° |

---

## 🚀 사용 방법

1. **색상 팔레트**에서 색상 선택
2. **전개도의 각 칸**을 클릭하여 색상 지정 (6면 × 9칸)
3. **해결하기** 버튼 클릭
4. 오른쪽 패널의 **단계별 안내** 따라 큐브 맞추기

---

## ⚙️ 기술 스택

- **언어**: 순수 HTML5 / CSS3 / Vanilla JavaScript
- **스타일**: 다크 테마, CSS 3D Transform
- **알고리즘**: IDA* (Iterative Deepening A*) + Facelet 치환 테이블
- **외부 라이브러리**: Font Awesome (아이콘), Google Fonts (Inter)
